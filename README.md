# MediSense AI

## Smart Patient Monitoring System

MediSense AI is a machine-learning portfolio project that demonstrates how artificial intelligence can analyze different types of healthcare-related data.

The application is built with Python, TensorFlow, Scikit-learn, and Streamlit.

## Features

### 1. Heart Disease Risk Prediction

* Uses patient health information such as age, blood pressure, cholesterol, chest pain type, and other clinical features.
* Uses a Logistic Regression model.
* Produces a lower-risk or higher-risk classification with an estimated model probability.

### 2. Chest X-ray Pneumonia Detection

* Accepts a chest X-ray image.
* Uses a Convolutional Neural Network.
* Classifies the image as `NORMAL` or `PNEUMONIA`.

### 3. Heartbeat Audio Screening

* Accepts `.wav` or `.mp3` heartbeat audio.
* Extracts MFCC audio features.
* Uses a Logistic Regression model to classify the audio as a normal or abnormal heartbeat pattern.

### 4. Human Activity Recognition

* Accepts `.avi`, `.mp4`, or `.mov` video files.
* Extracts 10 frames from each video.
* Uses a CNN and LSTM-based model.
* Recognizes the activities `Walking With Dog` and `Bodyweight Squats`.

## How to Run

### 1. Create and activate the virtual environment

```bash
python -m venv .venv
```

Windows PowerShell:

```bash
.venv\Scripts\Activate.ps1
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Start the Streamlit application

```bash
streamlit run app.py
```

The application will open in the browser at the local Streamlit address.
